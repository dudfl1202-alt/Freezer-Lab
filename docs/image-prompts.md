## 사용 방법

### Midjourney
1. Discord에서 `/imagine` 입력
2. 위 프롬프트 하나 복사 + 붙여넣기
3. `--ar 4:3 --v 6 --style raw` 추가
4. 4개 중 마음에 드는 것 선택 → Upscale
5. 다운로드 후 파일명을 `mp-b-001.jpg` 등으로 저장
6. `public/images/recipes/` 폴더에 업로드

### DALL-E 3 (ChatGPT Plus)
1. 프롬프트 그대로 복사 + 붙여넣기
2. "4:3 비율로 생성해줘" 추가 요청
3. 다운로드 후 저장

### 생성 후 자동 매핑

30장을 다 넣으시면 저한테 알려주세요. 파일이 있는지 체크해서 해당 레시피에 `imageUrl`을 자동으로 추가하는 코드를 만들어드립니다.
